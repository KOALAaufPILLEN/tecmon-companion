    GAMES · CS2 · RUNDENTIPPS

    Rundentipps sind aus

    Nutzt die offizielle Game State Integration von Valve. Der Companion liest nur deine eigenen Werte (Geld, HP, Waffen, Stats), keine Gegner. Tipps kommen nur in der Kaufzeit, nach deinem Tod und zur Halbzeit. Bei FACEIT oder Turnieren können eigene Regeln gelten.

      GAMES · DOTA 2 · TIPPS

      Dota-2-Tipps sind aus

      Nutzt die offizielle Game State Integration von Valve. Der Companion liest nur deine eigenen Werte (Gold, Last Hits, K/D/A, deine Items), keine Gegner, keine Karte, kein Roshan. Tipps kommen nur vor dem Horn, in Spielpausen, nach deinem Tod und am Matchende. Dota 2 braucht dafür in Steam die Startoption -gamestateintegration.

        // TECMON-ENGINE
        Eigene Aufnahme

        01 / VORBEREITEN
        Dein Aufnahme-Setup
        Das Windows-Setup richtet PostgreSQL, CS Demo Manager, HLAE und FFmpeg automatisch ein. Über „CS Demo Manager öffnen“ nutzt du die eingerichtete Verbindung. Demos können auf allen Laufwerken liegen.
        CS Demo Manager herunterladen ↗
        

        // LOKALE DATENBANK
        PostgreSQL einrichten
        Installation wird geprüft …
        CS Demo Manager benötigt PostgreSQL 17 oder neuer mit Server und Command Line Tools.
        Das Administratorpasswort wählst du im Setup. TecMon richtet ein eigenes Anwendungskonto und die Verbindung automatisch ein. Der private PostgreSQL-Bereich startet erst bei Bedarf.
        Offizieller Installer / Alternative ohne WinGet ↗
        Der Assistent öffnet bei Bedarf die interaktive Installation über WinGet. Windows-Adminfreigabe, Lizenzdialoge und Passwort bestätigst du im Installationsfenster. Nach der Einrichtung erneut prüfen und CS Demo Manager verbinden.
        

        02 / DEMOS LOKAL LADEN
        Sharecodes → Originaldemos
        Steam auf diesem PC anmelden, CS2 und CS Demo Manager schließen. Sharecodes von der Website einfügen oder deren Match-Datei über „Auftrag / Matches öffnen“ importieren. CS Demo Manager löst die Codes auf, lädt die Demos direkt von Valve und entpackt sie lokal. Keine Website-Secrets nötig. Abgelaufene Demos können nicht wiederhergestellt werden.
        

        03 / SZENEN ÜBERNEHMEN
        Deine Auftragsliste
        Im TecMon-Replay mehrere Spieler und Zeitbudget wählen, „In CS2 aufnehmen“ öffnen und die gemeinsame .tecmon.json-Datei hier importieren. Alle Szenen werden zu einem Video zusammengefügt.
