    // LOKALE DATENBANK

    PostgreSQL einrichten

    Installation wird geprüft …

    CS Demo Manager benötigt PostgreSQL 17 oder neuer mit Server und Command Line Tools.

    Das Administratorpasswort wählst du im Setup. TecMon richtet ein eigenes Anwendungskonto und die Verbindung automatisch ein. Der private PostgreSQL-Bereich startet erst bei Bedarf.

    Offizieller Installer / Alternative ohne WinGet ↗
    Der Assistent öffnet bei Bedarf die interaktive Installation über WinGet. Windows-Adminfreigabe, Lizenzdialoge und Passwort bestätigst du im Installationsfenster. Nach der Einrichtung erneut prüfen und CS Demo Manager verbinden.
    02 / DEMOS LOKAL LADEN

    Sharecodes → Originaldemos

    Steam auf diesem PC anmelden, CS2 und CS Demo Manager schließen. Sharecodes von der Website einfügen oder deren Match-Datei über „Auftrag / Matches öffnen“ importieren. CS Demo Manager löst die Codes auf, lädt die Demos direkt von Valve und entpackt sie lokal. Keine Website-Secrets nötig. Abgelaufene Demos können nicht wiederhergestellt werden.
